Configuration
---
Just use `goverlay`. It provides a visual interface to configure everything you would have to do manually otherwise.

Mangohud uses a config file located in `$XDG_CONFIG_HOME/MangoHud/MangoHud.conf`, which is usually the `~/.config/...` folder

Troubleshooting
---

To get CPU power consumption on Zen 4, you need to use `zenergy`
`paru -S zenergy`
